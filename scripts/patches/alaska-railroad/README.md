The Alaska Railroad's own GTFS file (alaskarailroad.com/GTFS) still carries 2024-25 dates.
These two files give its winter trains the 2026-27 dates from alaskarailroad.com/ride-a-train/schedules
(checked October 2026); the trains' stop times in the feed match that page.

- Aurora Winter Train: northbound Saturdays, southbound Sundays, Sept 19 2026 - May 9 2027
  (the Feb-Mar 2027 midweek trips aren't included: the page doesn't list their dates)
- Hurricane Turn (winter): first Thursday of each month, Oct 2026 - May 2027, none in March

fetch_gtfs.py uses these only while the railroad's own file has no trains in the coming weeks.
